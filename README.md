# Apex — Executive Command

Executive-grade task manager with dashboard, notifications, AI assistant, and responsive mobile/desktop layouts.

## Features

- **Dashboard** — KPIs, progress ring, priority focus, AI insights
- **Tasks** — categories, priorities, due dates
- **Habits** — weekly tracker and consistency
- **Apex AI** — local co-pilot for focus, prioritization, and task capture
- **Notifications** — overdue, due today, and high-priority alerts
- **Responsive** — mobile app UI under 768px; standard desktop layout with sidebar above

## Stack

HTML, CSS, JavaScript (no build step). PWA-ready via `manifest.json`.

## Run

Open `index.html` in a browser, or serve the folder with any static server.

```bash
npx serve .
```

Language: **English (standard)**.
